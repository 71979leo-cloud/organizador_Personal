# Lista de Funcionalidades Planeadas

El sistema contará con el siguiente conjunto de capacidades clave para la gestión de información:

- Alta de nuevas tareas pendientes.
- Visualización y búsqueda de tareas registradas.
- Edición y actualización de información de tareas.
- Cambio de estado de tareas a completadas.
- Creación y almacenamiento de notas personales.
- Creacion y almacenamiento de proyectos escolares.
