# Propósito del Proyecto

El proyecto **Organizador Personal** tiene como propósito principal proveer una aplicación básica en Python que permita a los usuarios administrar y organizar de manera sencilla sus tareas cotidianas y notas personales.

Esta etapa inicial se enfoca en preparar la estructura del proyecto, configurar el entorno virtual, gestionar dependencias y establecer las buenas prácticas para el control de versiones y trabajo colaborativo mediante Git y GitHub.
