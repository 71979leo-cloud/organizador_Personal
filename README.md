# Organizador Personal

## Objetivo
El objetivo de este proyecto es preparar la estructura inicial y el entorno de trabajo para una aplicación en Python que administre tareas y notas personales, aplicando un flujo de trabajo versionado y colaborativo con Git y GitHub.

- Python 3.x
- Git & GitHub
- Visual Studio Code
- Entorno Virtual (`venv`)
